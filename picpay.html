#overview

As the platform expanded its ecosystem, the challenge was to keep the experience seamless while integrating complex new financial services.

I worked as an iOS engineer for over four years across the User Activation, Wallet and Financial Products squads. I built and scaled core features, from onboarding and deposits to wealth-management tools, and every release had to meet bank-grade security standards without hurting performance.

#key features

Home screen

Built a dynamic banner system for quick remote configuration. Improved the suggestion list and added new elements in the scroll view using the Texture framework, prioritizing performance.

Wallet management

Redesigned the entire wallet feature with screen-reader accessibility, and implemented a credit/debit card manager for managing payment methods.

Savings account

Created a flexible savings account that lets users organize money into virtual piggy banks. I was involved from the start, including design research and refinement.

Transaction statement

Built a simplified statement screen that unified transactions from several microservices into one overview of the user's activity.
